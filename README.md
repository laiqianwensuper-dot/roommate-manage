# 合租管家 · 梧桐小屋

纯静态、无依赖的合租生活协作原型，可直接部署到 GitHub Pages 或 Vercel。交互由浏览器端 JavaScript 驱动，并使用 LocalStorage 在当前设备保存 Demo 状态。

## 当前产品结构

- 今日：只聚合“现在需要我处理什么”
- 值日：今日任务、本周轮班和换班反馈
- 物品：库存、补货认领、补货后加入临时 AA
- 小屋：成员、共同约定与小屋时光
- AA 一笔：作为临时共同开销工具，而非独立记账产品
- 创建/加入小屋：可切换当前空间的 Demo 状态

打开 `index.html` 即可本地预览；将三个前端文件部署到静态托管服务即可上线。
